# Kampfinsel Kampfrechner

Ein eigener Kampfrechner für [Kampfinsel](https://kampfinsel.com), kalibriert an echten Kampfberichten (Seeschlacht, Hafenverteidigung, Landkampf, Belagerung, Plünderung).

Läuft unter: **https://henges89.github.io/kampfinsel-rechner/**

Einfügen eines Spähberichts füllt die Verteidiger-Seite automatisch aus; eigene Flotte/Truppen/Forschung links eintragen. Die Herkunft jeder Konstante (verifiziert vs. geschätzt) steht im Footer der Seite.

Diese Seite ist der reine Rechner. Das Kalibrierungs-Material (echte Kampf-/Spähberichte, Modelltest) bleibt privat und wird nicht veröffentlicht.
